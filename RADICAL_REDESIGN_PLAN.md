# Radical Redesign Plan: From Streaming App to Film Archive

## Current State (What We Have)
- ❌ Horizontal scrolling carousels (every streaming app does this)
- ❌ Standard card grid layout
- ❌ Generic hero carousel
- ❌ Predictable section-by-section flow
- ❌ UI competes with movie posters

## Target State (Film Archive Aesthetic)

### 1. Homepage: Film Festival Program Layout
**Instead of carousels, create:**
- **Asymmetric poster wall** - Featured films larger, others smaller (like a curated gallery)
- **Editorial typography** - Section headers styled like film festival program notes
- **Film strip navigation** - Horizontal sections with perforation-style dividers
- **Masonry layout** for collections - Varying sizes, curated feel
- **Program-style metadata** - Director, year, runtime displayed like film credits

### 2. Hero Section: Cinema Curtain Reveal
**Replace carousel with:**
- **Single featured film** - Large, editorial treatment
- **Film program notes** - Synopsis styled like festival program
- **Credits-style metadata** - Director, cast, year in editorial typography
- **Curtain reveal animation** - Page load feels like curtains opening

### 3. Content Sections: Archive Catalog Style
**Replace horizontal scrolling with:**
- **Film strip metaphor** - Horizontal sections with subtle perforation borders
- **Asymmetric grid** - Featured items larger, creating visual hierarchy
- **Editorial cards** - Each card feels like a film archive catalog entry
- **No hover rings** - Subtle, elegant interactions

### 4. Typography Hierarchy: Film Program
- **Massive display type** for featured titles (like film festival posters)
- **Editorial serif** for synopsis (like program notes)
- **Monospace** for all metadata (year, runtime, rating)
- **Program-style** section headers

### 5. Layout Philosophy: Curated Archive
- **Asymmetric layouts** - Break from grids
- **Varying card sizes** - Featured content larger
- **Editorial spacing** - More breathing room, less density
- **Film strip navigation** - Sequential, frame-by-frame feel
